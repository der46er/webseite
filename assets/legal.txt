2. Third-Party Services & APIs ("Listening Right Now" Widget)
This website utilizes an external API to display live "listening right now" status updates. To display this information, your browser must establish a direct connection to the third-party servers providing this data. 

As a technical necessity of this connection, your IP address and standard browser request data (such as user agent and timestamp) are transmitted to the external API provider. This data transfer is required solely to fetch and display the live status widget.
