System Architecture & Packet Routing

Infrastructure & Static Hosting

This online presence is delivered as a static deployment utilizing the infrastructure of GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. St, San Francisco, CA 94107, USA). When loading these pages, your browser establishes a direct connection to GitHub’s global content delivery network. GitHub processes automated connection parameters (Server Log Files) strictly to ensure secure data transfer, load balancing, and network stability.

Hybrid Backend Relays (Cloudflare Tunnel)

To process dynamic background operations, selected sub-routes of this domain communicate with an isolated backend server infrastructure. This encrypted communication channel is established via a Cloudflare Tunnel daemon (Cloudflare, Inc., 101 Townsend St, San Francisco, CA 94107, USA).

The Cloudflare Tunnel forwards requests from the public internet directly to our internal processing server without exposing open inbound network ports to the public web. During this relay, data packets pass through Cloudflare's edge network to filter malicious traffic and secure server stability. No permanent storage of personal user metrics occurs beyond transient caching or temporary operational debugging profiles.
