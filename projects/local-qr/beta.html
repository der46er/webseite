How to use

  • 1. Type your desired text or URL in the input field.
  • 2. Select a social preset for quick profile templates.
  • 3. Customize the look using the gradient and color buttons.
  • 4. Choose PNG or JPG and click save, or print directly.
  • 5. Download the HTML (via Settings) to use this generator offline!
